# Electro Pi - Senior QA Automation Engineer Technical Assessment

This repository contains the automation solution developed for the Electro Pi Senior QA Automation Engineer technical assessment.

## Automation Framework

The solution uses:

- Playwright
- JavaScript
- Page Object Model (POM)
- Playwright API Testing
- Postman
- SQL
- GitHub Actions

Playwright was selected because it provides reliable cross-browser automation, built-in auto-waiting, API testing support, tracing, screenshots, video recording, and CI/CD integration.

## Project Overview

The automation solution covers:

- UI test automation
- REST API testing
- Authentication and token handling
- Positive and negative API scenarios
- Postman automation
- Database validation using SQL
- CI/CD integration with GitHub Actions
- Test reporting and failure diagnostics
